# Security Policy

</div>

Security issues should be reported privately.

## Reporting a vulnerability

Do not report security vulnerabilities through public Issues, Discussions, or Pull Requests.

Send vulnerability reports to:

**[pacotinhoproject@gmail.com](mailto:pacotinhoproject@gmail.com)**

Please include:

* A clear description of the vulnerability.
* The affected repository, component, or version.
* Steps to reproduce the issue.
* Potential impact.
* Proof of concept, if available.
* Suggested mitigation, if available.

Do not include unnecessary personal or sensitive information.

## Disclosure

Please do not publicly disclose a vulnerability before it has been reviewed and addressed by the maintainers.

This includes:

* Public Issues.
* Discussions.
* Pull Requests.
* Social media.
* Other public channels.

## Scope

This policy applies to security vulnerabilities found in Pacotinho Project repositories.

Third-party services and dependencies may have their own security reporting processes.

## Questions

For general security questions that are not vulnerability reports, use GitHub Discussions.
